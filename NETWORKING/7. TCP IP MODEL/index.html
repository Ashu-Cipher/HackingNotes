    TCP/IP Protocol Stack

    The Internet Protocol (IP)

    -> the protocol by which data is sent from one computer to another on the Internet
    - data is transferred in form of packet via logical network path in an ordered format controlled by the network layer
    - virtual circuits: the best paths for data travel
    - Basic Transfer Unit of data: | Datagram header | Datagram data area |
    - Versions: IPv4 ; IPv6

    The IP Datagram

    • self-contained, independent entity with sufficient information
    • synonymous with "packet"
    • info about destination and interpretation is in header
    • variable in size
      Packet should be
    • independent of specifics of network
    • independent of specifics of the path
    • understandable to any router along the way or the destination host's IP layer
      It doesn't handle
    • datagram duplicate
    • delay or out of delivery
    • corruption of data
    • datagram loss

    IPV4

    Header Format

    • gives info about data
    • Version: 4 bit field
      if IPv4: value= 4; IPv6: value=6
    • Header Length:
      4 bit field
      Help knowing where actual data begins
      = Header Length field value x 4 bytes
      Initial 5 rows of IP header are always used
      Min length(IP Header): 5x4=20
      Max length(IP Header): 20+40=60
    • Type of service
      8 bit field
      Used for Quality of Service
      How the datagram should be used
      also called Differentiated Service Code Point(DSCP)
    • Total Length
      16 bit field
      Min: 20 bytes
      Max: max value of 16 bit word = 65535 bytes
    • Identification
      16 bit field
      act as ID
      all fragmented datagram have same ID
    • DF Bit
      Do not fragment
      0: can be more fragmented
      1: can't be more fragmented
    • MF Bit
      More fragment
      0: last or only fragment of that ID
      1: more fragment of that ID
    • Fragment Offset
      13 bit field
      position of fragmented datagram in original datagram
      = no. of data bytes ahead of it in original datagram
    • Time To Live
      8 bit field
      max no of hops a datagram can take to reach destination
      TTL>=0 at destination: Accepted
      TTL=0 before destination: Discarded
    • Protocol
      8 bit field
      tells host about protocol used
      Protocol No.: ICMP: 1
      IGMP: 2
      TCP: 6
      UDP: 17
    • Header Checksum
      16 bit field
      contain checksum value
      used for error checking
    • Source IP address
      32 bit field
      contains logical address of sender
    • Destination IP address
      32 bit field
      contains logical address of reciever
    • Options
      0-40 bit fiels
      Used for: record route
      Source routing
      Padding
    The fields that may be modified
    • TTL
    • Options
    • Datagram Length
    • Header Length
    • Fragment Offset

    IPv6

    • developed by Internet Engineering Task Force(IETF)
    • deal with problem of IPv4 exhaustion
    • 128 bits address having space of 2^128
    • colon-hexa representation is used
    • 8 groups, each group represents 2 Bytes
    • Three addressing methods
    • Unicast: identifies a single network interface. packet is delivered to interface identified by that address
    • Multicast: used by multiple hosts. packet sent to this multicast address is distributed to all interfaces corresponding to that address
    • Anycast: assigned to a group of interfaces. packet sent is delivered to only one meber interface. updates routing tables.
    • Broadcast is not defined in IPv6

    Format:

    Header Format

    1. Version
      4 bits
      bit sequence: 0110
    2. Traffic Class
      8 bit
      indicate class or priority of IPv6
    3. Flow label
      20 bits
      label packets belonging to same flow
      help avoiding re-ordering
    4. Payload length
      16 bit
      indicates total size(data+ extension header)
      if payload length > 65535 bytes, jumbo header is used instead of extension header
    5. Next header
      8 bit
      indicate type of extension header
    6. Hop limit
      8 bit
      analogous to TTL
    7. Source address
      16 bytes
      128-bit IPv6 address of original source
    8. Destination address
      16 bytes
      IPv6 address of destination
      next router interface if routing extension header is present
    9. Extension Headers
      to rectify the limitations of IPv4 Options Field
      next header field tells about extension header 1

      IPv6 may contain 0, 1 or more extension headers but should be present in their recommended order

    Security Feature dependent on application inbuilt IPSEC
    Address Length 32 bits 128 bits
    Address Representation decimal hexadecimal
    Fragmentation performed by sender and forwarding routers only by sender
    packet flow identification NA uses flow label field
    Checksum Available NA
    Message Transmission Scheme Broadcasting Multicast & Anycast
    Header length variable, 20-60 bytes 40 bytes
