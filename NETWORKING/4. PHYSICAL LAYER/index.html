    Transmission Media

    Guided

    -> Wired Media

    Twisted Pair Cable

    -> Pairs of wires twisted
    - Purpose: cancel out EMI from other pairs and external source

    TYPES

    UTP
    -> Unshielded Twisted Pair
    -> Generally best option

    STP
    -> Shielded Twisted Pair
    -> Extra cancelation

    Advantages

    • cheap
    • easy to work

    Disadvantage

    • Low data rate
    • short range

    Coaxial Cable

    • type of copper cable
    • built with metal shield and other components
    • block signal interference
    • Primary user: cable TV company

    Advantage

    • used in high frequency application
    • improve shield effectiveness
    • high bandwidth
    • cost of cable is less

    Disadvantage

    • bulky, thick, stiff
    • expensive to install
    • security issue
    • grounding necessary

    Optical Fiber Cable

    -> transfer data signal in form of light

    Tyes

    Single mode fiber (SMF)
    Multi mode fiber (MMF)

    Advantage

    • Extremely high bandwidth
    • thin, light-weight
    • resistant to EMI
    • long distance
    • low security risk

    Disadvantages

    • cost
    • fragile
    • difficult to install
    • attenuation, dispersion
