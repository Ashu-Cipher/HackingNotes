    Open System Interconnection(OSI)

    Communication Architecture

    • strategy for connecting host computer and other equipments
    • defines necessary elements for data communication between devices
    • defines a standard for the communication hosts
    • adds flexibility

    The OSI Reference Model

    • the Primary Architectural model for inter-computer communications.
    • describes how data makes its way from an application programme to another application programme through a network medium
    • divides the problem of moving data into SEVEN smaller and more manageable problems.
    • this separation is known as layering

    LAYER 7: Application Layer

    • top layer
    • provides interface
    • Responsibility: provide service to user

    LAYER 6: Presentation Layer

    • translate data for network communication and vice versa
    • responsible for protocol conversions, encryption/decryption, data compression/decompression
    • redirector operates at this layer

    LAYER 5: Session Layer

    • enable two networked resource to hold ongoing communications across a network
    • exchange of data during that session
    • responsible for initiating, maintaining and terminating sessions
    • responsible for security and access control
    • responsible for synchronization and checkpoint services

    LAYER 4: Transport Layer

    • manages transmission of data across a network
    • manages flow of data between parties by making packets
    • reassemble packets at receiving end
    • provide acknowledgement of successful transmission and request resend for errored packets
    • responsible for delivery from one process to another

    LAYER 3: Network Layer

    • handles addressing and translation for packets
    • decides route transmission between computers
    • handles decision needed to get data from one point to next
    • also handles packet switching and network congestion control

    LAYER 2: Data Link Layer

    • Methodology: 5. DATA LINK LAYER
    • handles packets between Network layer and Physical layer
    • handle conversion of data into raw and vice versa
    • handles framing

    LAYER 1: Physical Layer

    • Devices: 4. PHYSICAL LAYER
    • convert bits into electrical signals and vice versa
    • manages interface & Medium
    • tells software what needs to be sent
    • bottom layer
    • responsible for movement of bits from one hop to next
