# Internet Connections
## Internet backbone
-> A set of high speed network that carry Internet traffic

## Internet Service Provider (ISP)
-> Company that provide the access of network to other companies or individual

## Technologies used
- Phone modem: convert computer data to audio signal and transfer using telephone line, modem at destination convert it into data.
- Digital Subscriber Line(DSL): Uses regular copper phone lines to transfer digital data
- Cable modem: uses cable TV line

### Broadband
-> Connection in which speed is faster than 128 bps
- DSL, cable modem
- Speed for download differ from upload
