## 🛠️ Core Documentation Modules

### 🌐 Web Application Security
* **Vulnerability Labs:** Structured notes and writeups on targeted environments (e.g., bWAPP, DVWA, PortSwigger).
* **Injection Vectors:** Active payloads and bypasses for SQLi, Command Injection, and XSS.
* **Authentication & Session Management:** Mechanized testing for broken authentication, JWT manipulation, and OAuth flaws.

* **Reconnaissance & Enumeration:** Automated asset discovery pipelines and advanced scanning flags.
