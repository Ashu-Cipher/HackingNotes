## HUB
- connect computer together in star topology
- increases the chance of collision
- operate in physical layer of OSI model
- no intelligence
- flood incoming packet to all ports

## Repeater
-> Regenate weak signals to original level
- increase signal range

## Modem
- convert digital -> sound from sender side
- sound -> digital on receiver side
- classified by speed
## NIC
-> Network Interface Card
- provide MAC address
- hardware to allow computer to communicate on network
- OSI layer 1 & 2

## Switches
-> Intelligent HUB
- provide traffic control for packets
- uses database of MAC addresses to determine location
- OSI layer 2
## Bridge
-> Intelligent repeater
- uses database of MAC addresses to determine location
- database is created dynamically as computers communicate
- OSI layer 2
## Routers
- route info between LANs
- divide broadcast domain
- OSI layer 3

## Gateways
-> protocol converters
- software in Routers
- establish communication between different systems/protocols
- can operate at any network layer
## WAP
-> Wireless Access Point
- wireless communication device to connect with wireless network
- can relay data between wired and wireless devices on network
