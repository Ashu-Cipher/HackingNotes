## OSI vs TCP/IP

| OSI                                                                                                  | TCP/IP                                                                                                    |
| :--------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------- |
| 1. generic, protocol independent standard, act as communication gateway between network end and user | 1. based on standard protocols, it is a communication protocol, it allow connection of hosts over network |
| 2. transport layer gurantees packet delivery                                                         | 2. doesn't gurantees packet delivery, still more reliable                                                 |
| 3. follow vertical approach                                                                          | 3. follow horizontal approach                                                                             |
| 4. separate Presentation and Session Layer                                                           | 4. does't have separate layer for these                                                                   |
| 5. Transport Layer is connection oriented                                                            | 5. Transport layer is both connection oriented and connectiom less                                        |
| 6. Network layer is both connection oriented and connection less                                     | 6. Connection layer is connection less                                                                    |
| 7. a reference model                                                                                 | 7. implementation of OSI Model                                                                            |
| 8. doesn't fit protocol                                                                              | 8. can fit protocol                                                                                       |
| 9. protocols are hidden, hence replacable                                                            | 9. replacing protocol isn't easy                                                                          |
| 10. protocol independent                                                                             | 10. protocol dependent                                                                                    |
| 11. has 7 layers                                                                                     | 11. has 4 layers                                                                                          |
