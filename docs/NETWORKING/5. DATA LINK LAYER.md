# Switching
-> mechanism of communication made up ofseries of interconnected nodes called switches.
-> uses **STAR TOPOLOGY**
![[Pasted image 20260617213620.png]]

## Types:
![[Pasted image 20260617213718.png]]

## Message Switching
- each message is treated as independent unit
- each intermediate device store it until next is ready to receive it
- Store and Forward Switching
![[Pasted image 20260617214048.png]]

### Advantages
- multiple devices share same channel
- congestion can be reduced
- unlimited message length supported
### Disadvantage
- not compatible for video and audio
- costly
- security issue
- not reliable

## Circuit Switching
-> generally used in public network
-> handle voice and digital data
-> dedicated link/path established and maintained for entire duration of conversation
![[Pasted image 20260617214834.png]]

### Advantage
- guranteed data rate
- no waiting time
- suitable for long cont transmission
### Disadvantage
- others can't use same channel
- more bandwidth required
- time required for physical link establishment

## Packet Switching
-> data divided into fixed sized packets
-> routers direct packets between networks
![[Pasted image 20260617215402.png]]

### Advantage
- efficient use of network
- high data transmission
- no big memory requirred
- no dedicated path required
- suitable for video/voice calls
- less usage cost
### Disadvantage
- order mismatch
- transmission delay
- packet loss
- implementation cost
- security issue
