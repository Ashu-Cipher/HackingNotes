## Information Security Threats

### Threat: 
-> a constant danger to an asset
-> can be person, object or event
-> can be categorized and ranked

#### Types
1. Inadvertent threats: human failure
2. Physical disasters: natural disasters
3. Technical failures: hardware or software
4.  Deliberate acts: hacking, espionage
