# Hacking
-> very wide term
-> "Hacker" term was introduced in 1960s at MIT
-> end of 1960s, ARPANET found by US military
-> No standard definition

## Hacker
"Hacking has evolved from teenage mischief into a billion dollar business"
-> Using skills and knowledge to gain unauthorized access to a software, computer, or a network
-> uses own tools and techniques
-> NOT always bad
-> Prison or Million
-> Most Risky Profession

"The quieter you become, the more you are able to hear."

# Ethical Hacking
-> Performed by a company or individual to help identify potential threats
-> Search for any weak points that could be exploited by malicious hackers
-> Way more wider than we think!


## Ethical Hacker
-> Security Professional
-> Test security and identify loopholes
-> Reports and Analysis
-> Authorized with proper permissions
